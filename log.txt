### 📅 Day 1: Express Server Setup

* ✅ **What I built:**
  Set up a Node.js backend using Express. Created two routes:

  * `/` → returns a basic server status message
  * `/test` → returns a JSON response to verify API functionality

* 🧠 **What I learned:**

  * How to initialize a Node.js project using npm
  * How to install and use Express
  * How to create routes and handle HTTP responses (`res.send`, `res.json`)
  * Difference between development and production scripts (`dev` vs `start`)
  * Importance of using environment variables (`process.env.PORT`) for deployment
  * Role of nodemon in improving development workflow

* ⚠️ **Problems faced:**

  * Confusion about port handling (hardcoded vs dynamic)
  * Understanding proper script setup in `package.json`

* 🔧 **How I solved them:**

  * Used `process.env.PORT || 3000` for flexible port configuration
  * Separated scripts into `dev` (nodemon) and `start` (node)
  * Moved nodemon to `devDependencies`

* 🚀 **Next step:**
  Deploy the server to a public platform and make it accessible via a live URL

### 📅 Day 4: Handling Slack Input

* ✅ **What I built:**
  Enhanced the Slack bot backend to read user input from slash commands and respond dynamically based on the provided text.

* 🧠 **What I learned:**

  * How to access request data using `req.body` in Express
  * How Slack sends data in POST requests (especially the `text` field)
  * Importance of using middleware (`express.urlencoded`) to parse incoming data
  * How to create dynamic responses instead of static messages
  * Basic input validation techniques

* ⚠️ **Problems faced:**

  * Initially used incorrect syntax (`req.body()` instead of `req.body`)
  * Did not understand why request body was undefined
  * Handling cases where no input is provided

* 🔧 **How I solved them:**

  * Added `express.urlencoded()` middleware to parse incoming request data
  * Corrected usage of `req.body`
  * Extracted `text` field from Slack request
  * Implemented validation to handle empty input

* 🚀 **Next step:**
  Validate the input URL and integrate Google PageSpeed Insights API to perform real performance analysis
