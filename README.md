
# 🚀 Slack Bot – PageSpeed Insights Report

This project is a backend application built using **Node.js and Express** that integrates with the Google PageSpeed Insights API to analyze website performance and deliver structured reports via Slack.

## 📌 Project Goal

To build a Slack bot that:

* Accepts a URL through a Slack command
* Fetches performance data from Google PageSpeed Insights
* Returns a clear and structured performance report back to Slack

---

## 🛠️ Tech Stack

* Node.js
* Express.js
* Slack API (for bot integration)
* Google PageSpeed Insights API

---

## 🚀 Features

* REST API built with Express
* Structured routing and response handling
* Environment-based configuration for deployment readiness
* Scalable backend architecture for API integrations

---

## ⚙️ How to Run Locally

```bash
npm install
npm run dev
```
